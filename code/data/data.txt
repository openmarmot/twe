# squad_data table

chance_1944 and chance_1945 are the relative chance that a unit will be
available that year out of 100.

100 = ubiquitous in a typical mixed force that year
 50 = common but not standard in every battlegroup
 15-25 = regular minority / occasional attachment
  5-10 = uncommon specialist
  1-4  = rare (dozens to low hundreds in the whole army)
  0    = not fielded that year

Scaled from 1944-45 inventory and production share of the field army
(Eastern Front weighted), not from "did this vehicle exist."
Camo skins share the base squad's chance in the battlegroup generator.

# scenario_data table

Predefined tactical scenarios for the Scenario menu.

The game only reads this table. Edit rows here; startup does not
insert or update them. Every row appears in the Scenario menu.

Columns:
  sort_order            menu order
  name                  unique display name
  description           text shown in the Scenario menu
  year                  1944 or 1945 (used by battlegroup_generator)
  attacking_faction     german / soviet
  defending_faction     german / soviet / none / contested
  map_areas             comma list: town, airport, rail_yard
  german_squads         "Squad Name:count, Squad Name:count"
  soviet_squads         same format
  german_random_points  extra battlegroup_generator budget
  soviet_random_points  extra battlegroup_generator budget

The fixed squad list is the core force. random_points buys a small
random attachment so replays of the same scenario are not identical.

# names table

Male first and last names. name_gen pairs every first with every last
for that ethnicity at startup.

ethnicity: german, soviet, polish.
Civilians use polish.
name_type: first or last.

The name column is unique across the whole table. The same spelling
cannot be stored twice, even for a different ethnicity or name_type.
Local spellings are how shared names stay distinct (Karl / Karol,
Josef / Józef, Alexander / Aleksander / Aleksandr).

German names are the 1910-1925 male cohort, including Austrian
surname spellings (Mayer, Huber, Gruber). Soviet is Russian
transliteration, with Ukrainian surnames and a smaller share of
other Red Army surnames in the same pool. Polish is the civilian
pool for the eastern-front maps.
